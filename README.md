# MacroBox - Boîtier de Macros USB

MacroBox est un logiciel qui permet de configurer et utiliser un boîtier USB avec 12 boutons pour exécuter des actions sur votre ordinateur. Branchez votre boîtier, configurez vos boutons, et utilisez-les pour gagner du temps au quotidien.

## Installation

Téléchargez la dernière version depuis les releases GitHub. Lancez le fichier `MacroBox.exe` et l'application s'ouvrira.

## Utilisation

### Configuration d'un bouton

1. Branchez votre boîtier USB
2. Sélectionnez le périphérique dans la liste
3. Cliquez sur un bouton (B1 à B12)
4. Choisissez ce que vous voulez faire :
   - **Taper du texte** : Entrez le texte que vous voulez taper
   - **Combinaison de touches** : Sélectionnez une combinaison comme CTRL+C, CTRL+V, etc.
   - **Lancer une application** : Recherchez et sélectionnez une application
5. Cliquez sur "Sauvegarder"

### Exemples d'utilisation

- CTRL+C pour copier
- CTRL+V pour coller
- WIN+L pour verrouiller Windows
- Taper automatiquement votre email
- Ouvrir rapidement vos applications favorites

### Formats disponibles

- **Texte** : Tape automatiquement du texte
- **Combinaisons de touches** : CTRL+C, CTRL+SHIFT+ESC, etc.
- **Touches spéciales** : ENTER, TAB, ESC, F1-F12, etc.
- **Applications** : Lance une application installée sur votre ordinateur

## Fonctionnalités

- Reste en arrière-plan : L'application se cache dans la zone de notification
- Menu rapide : Clic droit sur l'icône pour afficher, masquer ou quitter
- Recherche d'applications : Trouvez rapidement vos applications favorites
- Support des raccourcis : Utilisez les raccourcis de votre menu Démarrer
- Plusieurs boîtiers : Connectez plusieurs boîtiers en même temps
- Validation automatique : Les macros sont vérifiées pendant que vous les tapez

## Dépannage

Si votre boîtier n'est pas détecté :
- Vérifiez que le câble USB n'est pas en charge uniquement
- Installez les drivers nécessaires si demandé
- Vérifiez que le boîtier est bien branché

Si les macros ne fonctionnent pas :
- Vérifiez que le périphérique est sélectionné dans la liste
- Vérifiez que la syntaxe est correcte
- Assurez-vous que l'application existe si vous utilisez le format application
